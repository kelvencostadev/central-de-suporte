# CH-001 — Computador lento

**Tipo:** Estudo de caso simulado  
**Categoria:** Suporte técnico N1  
**Sistema operacional:** Windows 11  
**Status:** Concluído no cenário de treinamento

## 1. Descrição do problema

Usuário relata lentidão ao iniciar o computador e demora para abrir aplicativos. O problema começou há alguns dias e ocorre principalmente após iniciar o Windows.

## 2. Sintomas relatados

- Inicialização demorada.
- Aplicativos demorando para abrir.
- Travamentos durante o uso.
- Lentidão após iniciar vários programas.

## 3. Ambiente do cenário

- Memória RAM: 16 GB.
- Armazenamento: SSD.
- Sistema operacional: Windows 11.

## 4. Investigação inicial

No cenário simulado, o Gerenciador de Tarefas apresenta:

| Recurso | Resultado hipotético |
|---|---:|
| CPU | 95% |
| Memória RAM | 90% |
| Disco | 15% |

Os valores representam um cenário fictício para treinamento, não medições de um computador real.

## 5. Análise técnica

O alto uso de CPU e memória pode contribuir para a lentidão. Entretanto, esses indicadores não identificam sozinhos a causa.

O próximo passo é ordenar os processos pelo consumo de CPU e memória, identificar os principais consumidores e verificar se existe relação entre o consumo e os sintomas relatados.

## 6. Plano de ação

1. Identificar os processos com maior consumo.
2. Verificar se os processos são esperados e necessários.
3. Investigar aplicativos iniciados automaticamente com o Windows.
4. Aplicar uma correção adequada somente após identificar a causa provável.
5. Repetir os testes para comparar os resultados.

## 7. Validação da solução

A solução só será considerada eficaz se, após a correção, houver redução do consumo excessivo e melhora perceptível na inicialização e abertura dos aplicativos.

**Resultado:** etapa de validação descrita para fins de treinamento. Não foi executada em um computador real neste estudo de caso.

## 8. Aprendizados

- Coletar evidências antes de alterar o sistema.
- Diferenciar sintomas de causas.
- Evitar finalizar processos desconhecidos.
- Registrar procedimentos e resultados.
- Validar a solução antes de encerrar um chamado.

## Observação

Este é um estudo de caso fictício para desenvolvimento de habilidades de diagnóstico e documentação em Suporte Técnico N1. Os valores e procedimentos descritos não representam um atendimento real.
