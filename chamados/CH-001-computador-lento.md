# CH-001 — Computador lento

## 1. Descrição do problema

O usuário relata que o computador está lento para iniciar o sistema e abrir programas.

## 2. Sintomas relatados

- Demora para iniciar o Windows.
- Programas demoram para abrir.
- Lentidão durante o uso.

## 3. Verificações iniciais

- [ ] Verificar quando o problema começou.
- [ ] Conferir o uso de CPU, memória e disco no Gerenciador de Tarefas.
- [ ] Verificar o espaço disponível no disco.
- [ ] Identificar programas que iniciam junto com o Windows.
- [ ] Verificar se existem atualizações ou alertas do sistema.

## 4. Hipóteses de causa

- Pouca memória disponível.
- Muitos programas em execução.
- Pouco espaço em disco.
- Aplicativo consumindo recursos excessivos.
- Possível problema de hardware ou software.

## 5. Procedimento de solução

A solução será definida de acordo com os resultados das verificações. Evitar desativar processos desconhecidos ou excluir arquivos sem confirmar sua necessidade.

## 6. Resultado

**Status:** Em análise.

O chamado será atualizado após os testes e a confirmação da causa.
